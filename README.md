A professional, function-driven command-line coffee machine simulation built using Python. Developed as part of the #90DaysOfCode challenge, this project focuses on clean code practices, modular design, and simulating real-world logic such as resource management, payment handling, and user interaction

---
# 🚀 Features

☕ Multiple drink options (Espresso, Latte, Cappuccino)

🧮 Resource management system (water, milk, coffee)

💰 Coin-based payment processing

🔄 Change calculation & profit tracking

📊 Machine status report (report command)

❌ Graceful handling of invalid input

🧱 Modular & readable function-based structure

⌨ Beginner-friendly command-line interface

🧪 Excellent practice project for Python fundamentals
